# frontend

The UI for the ONDC Admin Monitoring Dashboard. See the
[root README](../README.md) for what the app is and how to run it, and
[`CLAUDE.md`](./CLAUDE.md) / [`CONVENTIONS.md`](./CONVENTIONS.md) for how it is
built.

```bash
npm install
npm run dev      # http://localhost:5190, proxies /api to $BACKEND_URL
npm run build    # tsc -b && vite build
npm run lint
```
